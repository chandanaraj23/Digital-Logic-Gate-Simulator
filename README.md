Digital Logic Gate Simulator

Project Description

The Digital Logic Gate Simulator is a web-based application designed to simulate basic digital logic gates.

Features

- AND Gate
- OR Gate
- NOT Gate
- Simple and user-friendly interface
- Real-time logic simulation

Technologies Used

- HTML
- CSS
- JavaScript

Project Files

- index.html
- style.css
- script.js

How to Run

1. Download or clone the repository.
2. Open "index.html" in a web browser.
3. Select logic gate inputs and observe the output.
